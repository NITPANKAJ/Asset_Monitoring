JSDG Asset Dashboard - Updated HTML + Google Sheet Version

Features added:
1. Faster dashboard using browser cache.
2. Google Sheet refresh happens in background.
3. Manual Refresh Data button fetches latest sheet data.
4. Automatic background refresh every 5 minutes.
5. KPI cards are clickable.
6. Chart bars are clickable.
7. Clicked analysis opens a detail popup with matching records.
8. Train and Rake KPI cards show a grouped summary first.
9. Detail popup includes its own search box.
10. Data Entry also uses cached data for faster opening.

Files:
- index.html
- data-entry.html
- analysis.html
- app.js
- style.css

Run with VS Code Live Server or any normal static web host.
Google Apps Script URL is already configured in app.js.
