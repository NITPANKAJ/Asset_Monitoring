JSDG Asset Dashboard - Role Based

Files:
1. index.html         - Login page
2. data-entry.html    - Add/Edit/Delete records
3. analysis.html      - Read-only analysis dashboard
4. app.js             - Shared logic/data
5. style.css          - Styling

Default accounts:
Data Entry: entry / entry123
Analysis:   analysis / analysis123
Admin:      admin / admin123

IMPORTANT:
For best results, run this folder through localhost (for example XAMPP htdocs),
then open http://localhost/JSDG_Asset_Dashboard_Role_Based/

This is still a simple browser-based system. For strong security and multiple
computers/users sharing one central database, use PHP + MySQL.
